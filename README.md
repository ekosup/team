# Team Board

Single-page Kanban board for tracking dev progress across modules, timelines, and targets. Runs entirely on Cloudflare Workers + D1 (see `.claude` plan / `cloudflare-fullstack-app` skill for the architecture rationale).

Roles:
- **Admin** — static bearer key (`ADMIN_API_KEY` secret). Manages managers (generate/revoke access keys), team boards, and views stats at `/admin`.
- **Manager** — logs in with an access key generated by Admin. CRUD their team board's buckets/tasks at `/board`.
- **Guest** — read-only public link at `/p/:slug`, no auth, only works if the board is toggled public.
- **Requester** — one-way ticket form at `/t/:slug`, no auth. Email must match the board's allow-list (exact email or `*@domain`, set by the manager under *Pengaturan*). Managers accept a ticket into the leftmost column or reject it.

Task PIC is a dropdown from the board's assignee list (also under *Pengaturan*). Migration `0004` seeds it from existing free-text PICs.

## Runbook

All commands are defined as self-documented [mise](https://mise.jdx.dev) tasks — run `mise tasks` to list them.

### First-time setup

```bash
mise run install
mise run bootstrap:d1        # paste returned database_id into wrangler.toml
mise run bootstrap:kv        # paste returned id into wrangler.toml
mise run bootstrap:secrets   # pick a strong static token, this is the Admin login
mise run migrate:remote      # apply migrations/0001_init.sql to prod D1
```

For local dev, put the same secret name into `.dev.vars` (gitignored):

```
ADMIN_API_KEY=dev-local-admin-key
```

Then `mise run migrate` and `mise run dev` (runs worker + frontend together).

### Day to day

```bash
mise run typecheck   # worker + frontend
mise run test        # worker vitest (schemas, crypto)
mise run deploy      # builds frontend, ships one Worker (API + static assets)
```

## Agent-driven operation

`GET /api/admin/schema` (no auth) returns every write endpoint's shape — use it instead of reading source when scripting against the API. A companion Claude Code skill (mirroring `ekoeis`) can be added later for remote ops (generate manager keys, create boards) from any session; see `~/.claude/skills/cloudflare-fullstack-app/SKILL.md` §7 for the pattern.
